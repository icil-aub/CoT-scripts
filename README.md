# CoT-scripts

Scripts and fonts for the City of Tenants Experience Builder app, served by GitHub Pages at `https://icil-aub.github.io/CoT-scripts/`.

**Don't edit files here.** They're copied from the City of Tenants source repository with `tools/deploy_scripts.sh`, and the next copy overwrites any change made here.

| File | Loaded by |
| --- | --- |
| `header.js` | The loader in the shared header widget |
| `footer.js` | The loader in each page's footer widget |
| `common.js` | The Survey, Map, Statistics and About page scripts |
| `fonts/` | The footer, Landing, About, Statistics and Survey scripts |
